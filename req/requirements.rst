Requirements
============

.. req:: Benutzer kann sich anmelden
   :id: REQ_LOGIN_01
   :status: open

   Der Benutzer kann sich mit **Benutzername** und Passwort anmelden.

.. req:: Benutzer kann sich abmelden
   :id: REQ_LOGOUT_01
   :status: implemented

   Der angemeldete Benutzer kann seine Sitzung gezielt beenden.

.. req:: Passwort kann geändert werden
   :id: REQ_PASSWORD_01
   :status: implemented

   Der Benutzer kann sein Passwort ändern. Das neue Passwort wird nach
   erfolgreicher Validierung übernommen.
